# TerramineCoalMazeKeybinds
*Note: this requires iPhone mirroring, which is only available on macOS*

This script provides functionality for using keybinds (arrow keys) on the coal mine minigame in Terramine.

### How to use the script
Use a code editor such as PyCharm to run the script. Make sure your code editor has accessibility permissions.
Keybinds are disabled by default. Press '[' to enable them and ']' to disable them. Press 'h' for a full list of commands.
