# Terramine Coal Maze Keybinds
*Note: this requires iPhone mirroring, which is only available on macOS*

This script provides functionality for using keybinds (arrow keys or WASD) on the coal mine minigame in Terramine.

## How to use the script
- Copy the code from script.py and then use a code editor such as [PyCharm](https://www.jetbrains.com/pycharm/) to run the script.
- Make sure your code editor has accessibility permissions.
- Keybinds are disabled by default. Press **'['** to enable them and **']'** to disable them.
- Press **'h'** for a full list of commands (these will display in the python console). 
- The script only works while the phone mirroring window is maximized. Use **Command +** to maximize the window.
